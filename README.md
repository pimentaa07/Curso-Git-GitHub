# Curso TMW Git & GitHub



Um curso para iniciantes aprenderem a trabalhar com versionamento de código e repositórios remotos com GitHub.



Principais comandos bash:

-git init . (CRIAR O GIT)  
-rm -rf .git/ (apaga  o git) 
-git status 
-git add nome_arquivo 
-git commit -m "" (descrição do save) 
-git config --global user.email "gustavo.l.pimenta@ufv.br"
-git add nome_arquivo(atualizar) 
-git log (ver todos os saves) 
-git add . (atualiza tudo do arquivos) 
-git diff nome_arquivo (mostra oque foi alterado antes do save) 
-caso trave aperte Q 
-git reset nome_arquivo (apaga o commit feito) 
-git checkout -b nome_branche (criar nova branch e  tp pra ela) 
-git checkout nome_branch(tp outra branch) 
-git branch (mostrar branches) 
-git merge nome_branch(traz as alterações da branch) 
-git branch -D nome_branch(deletar branch)
